# My Sticky Note Application

# Overview -
#This repository contains a static web, application designed for creating and managing digital sticky notes.

# Features & Tech - 
The app allows users to add, organize and remove sticky notes directly within their browser window. It is built using standard web tools:
    HTML - Provides structure and layout
    CSS - Handles the visual styling, responsive design and sticky note aesthetics
    JavaScript - Manages DOM manipulation, user interactions and core application logic

# Project Structure - 
The repository follows a clean static web directory architecture to separate structure, presentation and logic:                  my-sticky-note-static/                                                                                                 |----- index.html                                                                                                     |-----css/                                                                                                            |       |----- style.css                                                                                              |----- js/                                                                                                            |       |----- script.js

# Getting Started & Deployment - 
#Local Execution:
  Because its a completely static application, no build tools, package managers or local web servers are required. To view the project locally, simply clone or download this repository, navigate to the my-sticky-notes-static/ directory and open the index.html file in any modern web browser.

#Live Deployment:
  This project is structured for deployment via GitHub Pages. To host it live, push the project files to a public GitHub repository, navigate to the repository's Settings and enable GitHub Pages on the main branch. The platform will automatically serve index.html as the entry point for the live URL.
